# ZMQ 通信架构文档

## 概述

本项目使用 ZeroMQ (ZMQ) 实现进程间和网络间的通信。架构与原始 `triple_imu_rs485_publisher_dual_cam_UI_voice.py` 完全一致。

## Socket 配置

### 发送端 Sockets (本机 A 端)

| Socket 名称 | 类型 | 方向 | 端口 | 目标 | 用途 |
|-------------|------|------|------|------|------|
| `control_push` | PUSH | connect | 5555 | B服务器 | 发送IMU/机械臂控制数据 |
| `debug_pub` | PUB | bind | 5560 | 本地UI | 发布调试数据供UI显示 |
| `lerobot` | PUSH | connect | 5559 | LeRobot | 发送数据到LeRobot |

### 接收端 Sockets (本机 A 端)

| Socket 名称 | 类型 | 方向 | 端口 | 来源 | 用途 |
|-------------|------|------|------|------|------|
| `video` | SUB | connect | 5557 | B服务器 | 接收视频流 |
| `audio` | SUB | connect | 5561 | B服务器 | 接收音频流 |
| `ui_command` | PULL | bind | 5562 | 本地UI | 接收UI控制命令 |

## Socket 类型说明

### PUSH/PULL (负载均衡模式)

- **特点**: 单向通信，支持多消费者负载均衡
- **用途**: 控制数据发送、LeRobot数据发送
- **A端 PUSH + connect** → **B端 PULL + bind**

### PUB/SUB (发布/订阅模式)

- **特点**: 一对多广播，支持主题过滤
- **用途**: 调试数据广播、视频/音频流分发
- **发送端 PUB + bind** ← **接收端 SUB + connect**

## 端口分配

| 端口 | 用途 | 绑定方 | 协议类型 |
|------|------|--------|----------|
| 5555 | 控制数据 | B端 | PUSH/PULL |
| 5557 | 视频流 | B端 | PUB/SUB |
| 5559 | LeRobot | B端 | PUSH/PULL |
| 5560 | 调试UI | A端 | PUB/SUB |
| 5561 | 音频流 | B端 | PUB/SUB |
| 5562 | UI命令 | A端 | PUSH/PULL |

## SSH 隧道配置

当无法直接访问 B 服务器时，通过跳板机建立 SSH 隧道：

```bash
# 跳板机: 202.112.113.78:2258
# 目标机: 202.112.113.74:2237

# 建立隧道 (映射多个端口)
ssh -N \
    -L 5555:localhost:5555 \
    -L 5557:localhost:5557 \
    -L 5559:localhost:5559 \
    -L 5561:localhost:5561 \
    -o ProxyJump=yhx@202.112.113.78:2258 \
    yhx@202.112.113.74 -p 2237
```

启用隧道后，A端将连接 `localhost:端口` 而非 `B服务器IP:端口`。

## 数据格式

### 控制数据 (发送到 B 端)

```json
{
    "raw_x": 150.5,
    "raw_y": 200.3,
    "raw_z": 100.0,
    "roll": 45.0,
    "pitch": 30.0,
    "gripper_state": 1,
    "timestamp": 1699123456.789
}
```

```json
}
```
